## [Unreleased]

### Added

- `add --all` copies every component in one command, instead of naming them one at a time. Components only: a block is a specific composition & pulls the components it is built from anyway, so name a block to get it. The bare word `add all` works too, but yields to a component of that name if one ever exists.
